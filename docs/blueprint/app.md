## Miyu 应用（miyu-app）

状态：草案（施工 AP-1，2026-11-03）。代替原来的桌面端外壳（`desktop.md`，Tauri 窗口，DT-1 到 DT-12）。

### 为什么换

2026-11-03 项目主人问「我们是否真的有必要做桌面版」，定：不做自己的窗口，照 oMLX 的样子做一个托盘程序加浏览器。

- 开箱即用照旧：装上 → 从应用菜单打开 → 自动用浏览器打开网页 → 开始用。和窗口版只差打开的是浏览器。
- 网页改了刷新就生效，不用重新出安装包；不再适配三种网页视图（WebKitGTK、WKWebView、WebView2），网页只照浏览器做。
- 局域网访问、im 这些要在后台一直跑的，本来就要一个常驻的图标表示「Miyu 在后台跑着」，托盘正好是它。
- 名字（同一天项目主人）：`-desktop` 是桌面版的意思，不合适，仓库、程序叫 `miyu-app`；给人看的地方（应用菜单、程序坞、任务栏、安装包、托盘提示）一律写「Miyu」，同 oMLX 只露一个名字。
- 谁想做自己的桌面版、手机 App，照网页和协议自己做，不归这里。

照 oMLX（README：原生菜单栏程序，只管起停、状态、崩溃了重启、更新、用量；界面都在服务给的网页里）：托盘不放界面，界面全在网页里。

### 它是什么

一个常驻的小程序 `miyu-app`：只有托盘图标（macOS 上是菜单栏图标），没有窗口。它不连核心以外的东西，调装在旁边的主程序 `miyu`，另照网页的做法连核心，看状态、收提醒（第 4、5 条）。

1. **从应用菜单打开**：起 `miyu-app`。已经有一个在跑的（单实例），交给它，它照第 2 条再开一次浏览器，自己退。
2. **打开网页界面**：跑 `miyu web`（核心、网页服务没在跑的由它拉起；带交接票，经跳转页交给系统的浏览器，网页 `web-ui.md`「二、miyu web」）。起来那一下开一次；托盘菜单「打开网页界面」、点托盘图标（Windows、Linux 左键）再开。浏览器装成了应用（网页的应用清单，见「网页要配的」）的，系统照它开成独立窗口。
3. **点托盘图标**：Windows、Linux 左键直接「打开网页界面」，右键出菜单；macOS 照菜单栏的习惯，点一下就出菜单。
4. **托盘菜单**（照 oMLX 菜单栏的那一份：头一行状态，下面按用途分组，组之间一根分隔线；只放人会来点的东西，别的都在网页里。2026-11-03 项目主人看过可交互的样板定：https://claude.ai/artifact/WWVU3J6jpQeBryGB84ZJqH）。从上往下：
   - **状态行**（灰字、前面一个小圆点，不能点）：
     - 「运行中」（绿点），局域网开着的写「运行中 · 局域网」；
     - 「正在启动…」「正在停止…」（黄点）、「已停止」（灰点）、「没有响应」（黄点，连得上、问不出话）；
     - 「出错了」（红点），下面一行小字写原因，照 `miyu` 的那一句，例如「这是旧版 Miyu 的数据根，新版不认」。
     - 不写「Miyu：」，菜单本来就是 Miyu 的（同一天项目主人）。
     - 状态照托盘自己连核心的那条连接来（同第 5 条，连上就是运行中，断了就是已停止），不定时去问。
   - **起停**，紧接在状态行下面（同一天项目主人：「停止」放状态行下面，「重新启动」单独一行放在它下面）：
     - 第一行「停止」（方块图标）：运行中、没有响应时；停着、出错了的时候这一行换成「启动」（播放图标）；正在启动、正在停止时灰着。
     - 第二行「重新启动」（转圈箭头图标）：一直在，运行中、没有响应、出错了时能点，已停止、正在启动、正在停止时灰着，不藏，免得菜单的行跟着状态跳。
     - 停止照原来外壳的做法 `miyu core stop`，网页服务、im 这些跟着停；托盘不退，状态行写「已停止」。重新启动是先停再拉起来。
     - 核心不是托盘叫停的、自己没了（崩了），状态行照实写，再弹一条系统通知「Miyu 意外停止了」，点了照「启动」做。托盘不自己悄悄拉起来：会话、网页、终端哪个头再连都会把核心拉起来（`connect_or_start`），用不着托盘另守着。
     - 图标照网页用的 Lucide（`square`、`play`、`rotate-cw`、`power`），线条、单色，画在打勾那一列。
   - **打开**：
     - 「打开网页界面」（默认项，加粗；同第 2 条。同一天项目主人：不叫「打开 Miyu」）；
     - 「设置…」（浏览器打开网页的设置；macOS 带 ⌘,）。
     - 没运行的时候点这两样，先把核心拉起来再开。
   - **软件包挂的入口**（同一天项目主人：别的程序要能往托盘菜单挂东西，例如 im 挂一个「打开通讯平台接入界面」）：
     - 装着、开着的包在清单里写了托盘入口的，一个包一行，名字照清单写（分语言），点了用浏览器打开那个包的后台页（`miyu web --package <编号>`）；没运行的先拉起核心。
     - 只能是「打开它的后台页」这一种，不挂任意命令：托盘不当启动器，也不开口子让包在这台电脑上跑别的东西。
     - 一个都没有的不出这一组。清单的写法要核心定（见「要核心给的」）。
   - **局域网**：
     - 「局域网访问」：打勾的开关，照配置 `web.listen`（`0.0.0.0` 是开）。打开前没设访问密码的，不开，改成用浏览器打开网页设置「通用」的「访问」一组，先设密码。
     - 开着时下面多一行「在手机上打开…」：一个小窗口，写局域网地址、画二维码（网页 `GET /listen` 回的 `lan`），手机扫了进登录页、输访问密码。
   - **这台电脑**：
     - 「开机时启动」：打勾的开关（Windows 照当前用户的 `Run` 注册表项，macOS 照登录项 `SMAppService`，Linux 照 `~/.config/autostart/miyu-app.desktop`）。开机起来的不开浏览器，只常驻。
     - 「打开日志所在的文件夹」：核心、网页、托盘的日志都在那里（数据根的 `var/log/`），出了问题照它查。
   - **关于、退出**：
     - 「关于 Miyu」：一个小窗口，写托盘、核心、网页三样的版本和钉的提交号，能复制。第一版不做自动更新（原来外壳第一节第 6 条）；以后做的话照 oMLX，有新版时这里多一行「安装更新…」。
     - 「退出 Miyu」（电源图标；macOS 带 ⌘Q）：先照「停止」把核心这些停掉，托盘再退。没停成的照退，日志记一行。
5. **系统通知**：浏览器关了也要收得到「回答完了」「等你回答」「等你确认」「定时任务跑完了」。托盘照终端的样子连核心（出示本机令牌，同网页服务读配置那样），订会话的状态和账号级的提醒（网页 `web.md`「系统通知」第 1、6 条同一套），只发「没有网页开着这个会话」（会话表那一项 `viewed` 不为真）的那些；标题、正文、`tag` 同网页第 2 条，图标用 Miyu 的 logo；点了用浏览器打开那个会话（`miyu web` 带上会话，见「要核心给的」）。和网页的分工：浏览器开着的时候网页自己会弹后台会话的，两边会重；这件等核心给「谁来发后台通知」的登记，没给之前托盘只在没有网页头连着核心时发。
6. **日志**：数据目录下 `miyu-app.log`，照原来外壳 DT-10 的轮转和限流。

### 装在哪

照原来外壳 DT-6、DT-7、DT-9 的打包流水线（`pins.toml` 钉核心、网页，`packaging/stage.py` 搭内容），换掉的只有程序：

| 平台 | 安装包 | 应用菜单里那一项 |
|---|---|---|
| Windows | 64 位 MSI（中、英、日），装进 `Program Files\Miyu\`，带官方 PowerShell 7 的 zip 版（DT-9）、许可证（DT-7） | 开始菜单「Miyu」，指向 `miyu-app.exe`（图形子系统，不闪命令行窗口） |
| macOS | dmg，`Miyu.app`，`LSUIElement`（不占程序坞，只在菜单栏） | 「应用程序」里的 Miyu |
| Linux | deb、rpm、AUR | `miyu.desktop`（`Exec=miyu-app`） |

安装包里不再有网页视图，Linux 上不再要 WebKitGTK。

### 网页要配的

- 应用清单（`manifest.webmanifest`、几种尺寸的图标）：Edge、Chrome 里能「安装为应用」，独立窗口、有自己的图标。本机地址能不能装、要不要 Service Worker，先实测再定。
- 手机上看到的几处先修（网页 W-1082）。Safari 先搁置（同一天项目主人）。

### 要核心给的

- 「谁来发后台通知」的登记（第 5 条）：照 HV-1 `session.viewing` 的思路，托盘连上时说一声，网页从会话表或握手里知道有托盘在发，就不再弹没人开着的后台会话。
- `miyu web` 打开时直接到某个会话、设置页（第 4 条「打开」那一组、第 5 条点通知）。
- 软件包清单里写托盘入口的一格（第 4 条「软件包挂的入口」）：名字分语言，指向它的后台页；`package.list` 照装着的带出来，托盘照它画。
- 托盘连核心时不拉起核心（同网页服务读配置那样），这样「已停止」才停得住。

### 原来外壳的去留

- 留下：托盘、单实例、调主程序（`program.rs`）、叫核心停（`quit.rs`）、日志（`log.rs`）、给人看的字、图标、打包流水线、许可证门禁和清单、随包的 PowerShell 7。
- 去掉：窗口、网页视图、导航和下载交给谁（`navigate.rs`、`download.rs`）、网页视图的通知替身（`notify.rs`、`resources/notification.js`）、macOS 的应用菜单（`menu.rs`）、窗口大小。
- 分支 `step/DT-8-通知`（DT-7、DT-8、DT-9）不照原样合：许可证（DT-7）、PowerShell 7（DT-9）挪进 AP-5；DT-8 的通知是给网页视图的，不要了，系统通知改成第 5 条。
- 程序换框架：只要托盘，不要网页视图，Tauri 换成更小的 `tray-icon` + `tao`（Tauri 自己的托盘就是它们），三个平台一份代码。
